Instruções de dobra para quarto/oitavo

Dobrar esses dois layouts é um pouco mais complexo do que o fólio de dobra única. Ambos foram projetados para que a primeira dobra seja paralela à borda curta do papel - por exemplo, se você segurar a folha na orientação retrato, vai dobrar a borda superior até a inferior. Um dos lados da folha terá números consecutivos atravessando essa dobra (ou seja, 3 e 30 na linha de cima, 2 e 31). Dobre para dentro nessa linha (de modo que o 3 fique encostado no 2, e o 30 no 31). A próxima dobra é ao longo do outro eixo do papel (paralela à borda longa original). No quarto, encontre o lado com os números mais próximos e dobre para dentro para juntá-los (eles serão consecutivos na folha mais interna). No oitavo, olhe a linha mais de baixo, encontre o par consecutivo e dobre para dentro. O oitavo tem uma última dobra, para a qual você deve encontrar o par restante mais próximo e dobrá-los juntos.

Ou, se preferir apenas decorar a ordem, depois de encontrar o lado da primeira dobra, a ordem é:
quarto - de cima para baixo, dobra apontando para longe de você; da esquerda para a direita, dobra apontando para você.
oitavo - de cima para baixo, dobra apontando para longe de você; da esquerda para a direita, dobra apontando para longe de você; de cima para baixo, dobra apontando para você.
